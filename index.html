    Credits & data sources

    Cosmic Explorer 3D is free and open source (MIT). It renders real data:

    • Earth: NASA Visible Earth Blue Marble (land/ocean), Black Marble 2016 (night lights), NASA cloud composite — public domain.
    • Moon: Solar System Scope color map (CC BY 4.0); NASA SVS LRO LOLA elevation.
    • Sun & planets: Solar System Scope texture maps — CC BY 4.0 (solarsystemscope.com/textures).
    • Night sky: ESO / S. Brunier Milky Way panorama (eso0932a) — CC BY 4.0.
    • Orbits: JPL approximate Keplerian elements (1800–2050); Meeus lunar theory; IAU rotation elements.
    • Voyager 1, Voyager 2 & Starman’s Tesla Roadster: NASA/JPL Horizons trajectory & osculating elements (`-31`, `-32`, `-143205` / `2018-017A`).
    • All 6,451 Confirmed Exoplanets: NASA Exoplanet Archive (`pscomppars` TAP catalog, 6,451 planets across 4,847 host systems) + Hipparcos/Gaia 3D coordinates.
    • Engine: three.js (MIT). Exoplanet surfaces, the Milky Way particle model and the cosmic web are artist’s impressions built from real structure data.
